## 2. Completed Steps

### 2.1 Cursor IDE Setup

- Installed **Cursor** on my laptop.
- Registered a **Cursor account** and selected the **Personal** plan.
- On first launch, opened the desktop editor via **File → Open Editor Window** (see [Challenges](#3-challenges-and-solutions) for why this step mattered).

### 2.2 GitHub Account and Repository

- Created a **GitHub account**.
- Created a **public GitHub repository** for this project.
- Used the repository to host this report (`Readme.md`).

### 2.3 Local Project Workspace

- In Cursor’s **Editor Window**, created a project folder named **`Sudaryanto Safei`**.
- Used **File → Open Folder** and selected that folder as the workspace root.

### 2.4 Extensions (Codex & Claude Code)

- Opened **View → Extensions**.
- Searched for and installed:
  - **Codex**
  - **Claude Code**
- Closed the Extensions panel with **Ctrl+Shift+E**.

### 2.5 README Report (Local + GitHub)

- In the project folder, created a new file: **`Readme.md`**.
- Drafted this portfolio report covering:
  - Installed applications
  - Steps completed
  - Challenges and solutions
- Used Cursor’s **AI chat** to refine and complete the report, then **reviewed and edited** the AI output before saving.
- On GitHub (next to the green **Code** button), added a new file named **`Readme.md`**, pasted the final report, and saved it to the remote repository.

### 2.6 Workflow Summary

```
Install Cursor → Register (Personal plan) → Open Editor Window
```

### Challenge 2: Git not installed — `Git: Clone` unavailable

**Problem:**  
I tried to connect the project to GitHub by pressing **Ctrl+Shift+P**, searching for **`Git: Clone`**, and pasting the repository URL. The command was **not available** because **Git** was not installed on my machine.
<img width="927" height="390" alt="image (7)" src="https://github.com/user-attachments/assets/3f894274-7b0c-4264-9bde-dfd45ee141de" />


**Solution:**  
I used a simpler workflow without cloning:

1. Created **`Readme.md`** locally in the **`Sudaryanto Safei`** folder in Cursor.
2. Wrote the full report (applications, steps, challenges) based on the assignment text.
<img width="1392" height="777" alt="image (8)" src="https://github.com/user-attachments/assets/dc81dea3-ea0b-4a50-91e8-e5ad7f8d1a24" />

3. On the **GitHub** website, added a new file **`Readme.md`** to the public repository and **pasted** the report content.
<img width="1511" height="772" alt="image (6)" src="https://github.com/user-attachments/assets/e49398da-c677-4fd4-bb3b-14fac3e74819" />

4. Saved the file on GitHub to publish the documentation.


**Lesson:** Git clone is optional for this task; creating the file locally and uploading via GitHub’s web UI is a valid alternative when Git is not yet installed.
